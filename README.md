# Hospital SQL Analysis

## 📌 Project Overview

This project analyzes hospital data using SQL to answer practical healthcare-related business questions.

The analysis covers patient counts, doctors, hospital stays, departments, cities, and medical expenses.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL

## 📊 Analysis Performed

1. Calculated the total number of patients.
2. Calculated the average number of doctors per hospital.
3. Identified the top 3 departments with the highest number of patients.
4. Identified the hospital with the highest medical expenses.
5. Calculated average daily medical expenses.
6. Found the patient/hospital record with the longest hospital stay.
7. Calculated total patients treated in each city.
8. Calculated the average length of stay for each department.
9. Identified the department with the lowest number of patients.
10. Calculated total medical expenses by month.
